Loader

loader.Loader(seed=None)

Shared lifecycle for all loader families.

The root owns source tracking, the load template, convenience construction, and timeline-creation surfaces. Payload-specific state and APIs belong to subclasses such as :class:EventLoader, :class:ManifestLoader, and :class:AlignmentLoader.

Every load, load_* and create_* method of every loader mints from the loader’s minter (see :meth:load): the groups, bundles, maps and flow control it builds without an ID of their own included.

Attributes

Name Description
metadata Aggregated source metadata.
parses One :class:~timetoalign.storage.Parse per source file read, in order.
sources The loaded sources: Path objects and ZIP members (zipfile.Path).

Methods

Name Description
clear Clear shared source state; the next load seeds as the first did.
create_bundle Create an alignment bundle when supported.
create_group Create a timeline group when supported.
create_timeline Create a timeline from the loaded payload.
create_timelines Create all timelines, optionally filtered by an implementation.
from_file Instantiate the loader, load paths, and return it.
from_registry A loader set up from registry’s parses, to refresh it with :meth:update.
load Load and accept one or more sources through the shared template.
update Re-read the loader’s sources and update registry with what they hold now.

from_file

loader.Loader.from_file(*paths, **kwargs)

Instantiate the loader, load paths, and return it.

A keyword the loader’s :meth:load declares keyword-only (what to read of a source, as performance of :class:~timetoalign.loader.alignment.MpmLoader) goes to :meth:load; every other keyword to the constructor.

Parameters

Name Type Description Default
*paths SourceLike Filesystem paths or members of ZIP archives (zipfile.Path), as :meth:load takes them. ()
**kwargs Any The keyword-only arguments of :meth:load, and the loader’s constructor arguments, seed among them (the seed of the loader’s ID minter). {}

Examples

>>> from zipfile import Path as ZipPath
>>> member = ZipPath("corpus.zip", at="corpus/measures/piece.measures.tsv")
>>> loader = Ms3Loader.from_file(member)

from_registry

loader.Loader.from_registry(registry, *sources, root=None, **kwargs)

A loader set up from registry’s parses, to refresh it with :meth:update.

The loader runs with the parameters (and the seed) the registry’s parses of this loader’s class recorded, and reads their source files, unless sources names what to read (a loader reading a folder, an archive or a project is given that). Nothing is read until :meth:update.

Parameters

Name Type Description Default
registry EventRegistry The registry to refresh, a timeline’s, a group’s or a bundle’s. required
*sources SourceLike What the loader reads, as :meth:load takes it; by default the source files of the parses, in order. ()
root Path | str | None The folder a relative source file of a parse lies in; by default the current one. None
**kwargs Any The keyword-only arguments of :meth:load, and constructor arguments, which must leave the parameters as the parses recorded them. {}

Returns

Name Type Description
Self The loader, its load call recorded but not run.

Raises

Name Type Description
ValueError If the parses of this class record two sets of parameters or seeds, the loader set up runs with other parameters than they record, or neither sources nor an parse names a source file.

load

loader.Loader.load(*sources)

Load and accept one or more sources through the shared template.

Each source is a filesystem path (Path or str) or a member of a ZIP archive (zipfile.Path), which is read without extracting the archive. Its entry in metadata["sources"] records path (for a member: the archive’s absolute path, and member, the member’s path inside it) and loaded_at.

Every ID the loader mints (events, timelines, maps, MatchClaims, Projections) comes from its :class:~timetoalign.core.ids.IdMinter, in the order the loader builds them. Every load call seeds a new one: the first call after the loader is made or cleared from the loader’s seed when one was given, else from :func:~timetoalign.core.ids.seed_from of the loader’s class name, its configuration (the constructor arguments that shape the events) and the SHA-256 digests of the call’s sources, in order; every later call from seed_from of the previous call’s seed and its own sources’ digests, so later sources count too. A fresh loader loading unchanged sources in the same calls mints the same IDs, in any process; IDs the source states are kept as they are.

Raises

Name Type Description
FileNotFoundError If a zipfile.Path names a member its archive does not hold.
ValueError If the loader reads one source and is given none or more than one, or any while it holds one (after clear() it reads one again). Nothing is parsed then.

update

loader.Loader.update(registry)

Re-read the loader’s sources and update registry with what they hold now.

The loader is cleared and its load calls are run again (those :meth:from_registry set up, or the loader’s own); each timeline :meth:create_timelines builds from them (and each descendant) then updates the registry’s timeline that holds the rows its locators name (else the one of its ID), one parse at a time (:meth:EventRegistry.update <timetoalign.storage.EventRegistry.update>): a row found again by its locator keeps its ID and takes the new content, position and parse; a new row is added with the ID it was given (minted from the content, as at every load); a row of the source no longer found is kept and marked vanished in the new parse. Nothing is deleted. Rows that name no locator (a child’s place, events made in code) are left as they are.

Parameters

Name Type Description Default
registry EventRegistry The registry to update: a timeline’s, a group’s or a bundle’s (:attr:Timeline.registry <timetoalign.timelines.Timeline.registry>). required

Returns

Name Type Description
list[str] The IDs of the registry’s timelines updated, in order.

Raises

Name Type Description
RuntimeError If the loader has no load call to run again (it read nothing, or in-memory content only).
ValueError If a timeline built holds rows that match no timeline of registry, by locator or by ID; nothing is updated then.
