How to Write the Registry and Share Tables in a Package

A bundle’s events in the registry and pre-parsed tables beside its manifest (to_file with events=True), IDs resolved through a manifest or a package root (resolve), a package of two bundles sharing its tables (Package, write_bundle, to_file), one manifest opened from package.yaml, the package check (package_problems), IDs held once in a package, and one bundle written into the package again

How to Write the Registry and Share Tables in a Package

A TimeToShare manifest holds the structure of its timelines and names no event. What lies on the timelines lies in Parquet tables beside it:

  • the registry, one row per ID the package can resolve: for every event its ID, its type, its timeline, its position on the axis of its timeline’s root and the parse that made it, and for a Projection the event it stands for; and a non-event row for every element of the manifest, every MatchClaim and every parse;
  • the Parse table, one row per parse: a run of a parser over a source file, or of a tool that made events without one (here the library, since the events are made in code);
  • one pre-parsed table per event type, holding what is particular to events of that type, keyed by their IDs and without positions (a Note table holding each note’s MIDI pitch); an event type whose events hold nothing but their ID and position has none, its events lying in the registry alone, and an event whose content can be read again from its source file is re-parsed instead and has no row there;
  • the MatchClaim table.

The manifest names the registry and the MatchClaim table in its resources. Several manifests can share their tables in a package: a folder whose package.yaml lists the manifests and the tables: the registry one Parquet file holding every row of every manifest, the Parse table one file, and the MatchClaim table and every pre-parsed table a folder tables/<Type>/ of the rows of every manifest. An ID combined with the location of a manifest, or of the package, resolves to what it names.

This guide writes a bundle with its tables, resolves IDs through its manifest, builds a package of two bundles with Package, opens one of its manifests, checks the package with TimeToShare’s package check, and writes one bundle into the package again.

Setup

Install the library with pip install timetoalign; the TimeToShare package, which defines the format and checks it, comes with it. Every file is written to a temporary directory.

The helper piece builds the bundle of one piece: a score of four notes, each with its MIDI pitch, a recording with an onset for each note but the last, a MatchClaim for each note and onset, and one claim giving the last note a position on the recording, where it gets a Projection. Every ID starts with the piece’s key, so that the IDs of two pieces differ. files lists a directory’s files and folders, show prints one key of a YAML file as the file holds it, values_per_file names the values of one column in each file of a table folder, and event_rows reads the event rows of a registry file.

import tempfile
from fractions import Fraction
from pathlib import Path

import pyarrow.compute as pc
import pyarrow.parquet as pq
from timetoshare import dumps, loads
from timetoshare.tables import package_problems

from timetoalign import (
    AlignmentBundle,
    ContinuousLogicalTimeline,
    ContinuousPhysicalTimeline,
    Package,
    Provenance,
    resolve,
)

FILES = Path(tempfile.mkdtemp())
EDITOR = "https://example.org/people/editor"
STATED = Provenance(stated_by=(EDITOR,), method="manual", date="2026-11-27")


def piece(key, pitches, onsets):
    """The bundle of one piece: a score, a recording, and their MatchClaims."""
    score = ContinuousLogicalTimeline(
        length=Fraction(4), uid=f"{key}_score", name="Score"
    )
    score.add_events(
        [
            {
                "id": f"{key}_n{number}",
                "event_type": "Note",
                "start": Fraction(number - 1),
                "duration": Fraction(1),
                "midi_pitch": pitch,
            }
            for number, pitch in enumerate(pitches, start=1)
        ]
    )
    recording = ContinuousPhysicalTimeline(
        length=4.0, uid=f"{key}_recording", name="Recording"
    )
    recording.add_events(
        [
            {"id": f"{key}_o{number}", "event_type": "Onset", "instant": seconds}
            for number, seconds in enumerate(onsets, start=1)
        ]
    )
    bundle = AlignmentBundle(id=key, name=key.title())
    bundle.add_timeline(score, as_group=f"{key}_score")
    bundle.add_timeline(recording, as_group=f"{key}_recording")
    pairs = [
        (f"{key}_n{number}", score.id, f"{key}_o{number}", recording.id)
        for number in range(1, len(onsets) + 1)
    ]
    pairs.append((f"{key}_n4", score.id, {"start": 3.5}, recording.id))
    bundle.create_match_claims(pairs, provenance=STATED)
    return bundle


def files(directory):
    """Every file and folder under a directory, folders ending in '/', sorted."""
    return sorted(
        str(path.relative_to(directory)) + ("/" if path.is_dir() else "")
        for path in directory.rglob("*")
    )


def show(path, key):
    """Print one key of a YAML file as canonical YAML."""
    print(dumps({key: loads(path.read_text(encoding="utf-8"))[key]}), end="")


def values_per_file(folder, column):
    """For each Parquet file of a table folder, the values of one column."""
    return {
        file.name: sorted(
            value
            for value in pc.unique(
                pq.read_table(file, columns=[column])[column]
            ).to_pylist()
            if value is not None
        )
        for file in sorted(folder.glob("*.parquet"))
    }


def event_rows(path, columns=("id", "kind", "timeline_id", "start", "location")):
    """The event rows of a registry file: the rows with a position."""
    table = pq.read_table(path)
    return [
        {name: row[name] for name in columns}
        for row in table.to_pylist()
        if row["start"] is not None
    ]

Write a bundle with its tables

to_file() always writes the Projections and Boxes the bundle holds, with the MatchClaim table. With events=True it also writes every other event type its timelines hold: the registry gets a row for each note and onset, and the notes their pre-parsed table, Note.parquet. An onset holds nothing but its ID and position, which its registry row states, so the onsets have no pre-parsed table, and nor have the Projections. The manifest itself still names no event.

from_file() reads the manifest and its tables, so the bundle read holds the notes and onsets again, beside the recording’s Projection and the MatchClaims; each note’s pitch is read from the Note table when its timeline’s events are first read. Written again, without events= (a manifest read with notes and onsets is written with them), it gives the same bytes, file by file.

Resolve an ID

resolve(target, id) answers what an ID names, through a manifest (a path or a file: URL) or a package root, always as a list: a timeline, an event as its scalar, a MatchClaim, a parse. An event’s position is the registry’s, on the axis of its timeline’s root. An ID nothing holds gives the empty list.

{
    "bach_n3": resolve(manifest_path, "bach_n3"),
    "bach_recording": resolve(manifest_path.as_uri(), "bach_recording"),
    "nothing": resolve(manifest_path, "bach_n9"),
}
{'bach_n3': [Event(id='bach_n3', start=Coordinate(Fraction(2, 1), quarters), duration=Duration(Fraction(1, 1), quarters))],
 'bach_recording': [ContinuousPhysicalTimeline(id='bach_recording', length=4.0, unit=seconds, events=4, children=0)],
 'nothing': []}

Build a package of two bundles

A Package takes a name (and an id, its IRI where it is published). write_bundle(bundle, url) adds a bundle as the manifest at url, relative to the package’s root. A new package only stages the bundles; to_file() writes them all at once, then package.yaml, then the registry’s non-event rows, into a folder that holds no package yet.

package = Package(name="Two pieces")
package.write_bundle(bach, "bach/manifest.yaml")
package.write_bundle(handel, "handel/manifest.yaml")
root = FILES / "pieces"
root.mkdir()
package_path = package.to_file(root / "package.yaml")

Open one manifest from the package

Package.from_file() opens the package at its package.yaml; manifests lists the manifests’ URLs and tables the table entries. bundle(url) reads one manifest as an AlignmentBundle, every table filtered to the timelines its resources list, so the Bach bundle holds its own events and claims and none of Handel’s. Its MatchClaims are the ones written; the package’s file orders them by timeline and ID and states each claim’s provenance in its own row, so compare the claims, not the tables.

opened = Package.from_file(package_path)
from_package = opened.bundle("bach/manifest.yaml")
{
    "manifests": opened.manifests,
    "table types": [table["type"] for table in opened.tables],
    "timelines read": from_package.timeline_ids,
    "events per timeline": {
        timeline_id: len(from_package.get_timeline(timeline_id).get_events())
        for timeline_id in from_package.timeline_ids
    },
    "same MatchClaims": set(from_package.get_match_claims())
    == set(bach.get_match_claims()),
}
{'manifests': ['bach/manifest.yaml', 'handel/manifest.yaml'],

Check the package

timetoshare.tables.package_problems() checks a package whole from its package.yaml: every manifest valid, every table file of its type and version, every resource naming a table of the package, every ID held once, every event row naming a parse and, where it gives a location, a table holding its content, the non-event rows agreeing with the manifests and tables, and the rows of each manifest checked against it. It returns the list of problems, here none. Package runs the same check after every write and raises its first problem, with every file restored.

package_problems(package_path)
[]

IDs are the package’s

Within a package, an event ID is held once among all events of every type, and a MatchClaim ID once among its MatchClaims; as Package writes a package, a timeline ID is held by one manifest. A bundle colliding with what the package holds is refused before anything is written, naming the ID and both holders. Writing the Bach piece a second time, under another URL, collides at its timelines.

try:
    opened.write_bundle(
        piece("bach", [60, 62, 64, 65], [0.0, 0.9, 1.8]), "bach_again/manifest.yaml"
    )
except ValueError as refusal:
    print(refusal)
timeline 'bach_recording' of the manifest 'bach_again/manifest.yaml' cannot join the package: its id 'bach_recording' is already held by a timeline of the manifest 'bach/manifest.yaml'

Write one bundle again

The editor adds a conceptual claim to the Bach bundle read from the package: the last note, which the detector missed, relates to the third onset. write_bundle() on a package lying on disk writes at once and replaces the manifest at that URL. The rows of its timelines leave the files holding them: the registry is rewritten whole with its rows, the pre-parsed and MatchClaim files keep the other manifests’ rows alone, and one new file per type holds the bundle’s rows. As with a single MatchClaim table, every claim the package held for the manifest must still be in the bundle, and the bundle may add claims.

from_package.create_match_claims(
    [("bach_n4", "bach_score", "bach_o3", "bach_recording")],
    synchronous=False,
    provenance=STATED,
)
opened.write_bundle(from_package, "bach/manifest.yaml")

A bundle read from a package names the package’s tables, which other manifests share. to_file() writes a manifest’s tables as single files beside it and refuses to write into a package’s tables; it names Package.write_bundle instead.

elsewhere = FILES / "elsewhere"
elsewhere.mkdir()
try:
    from_package.to_file(elsewhere / "bach.yaml")
