IIIFManifestLoader

loader.graphical.IIIFManifestLoader(seed=None)

Load image metadata from IIIF Presentation API manifests.

IIIF manifests contain canvas dimensions that represent image sizes. This loader extracts width/height for use with graphical timelines without needing to download or load the actual image files. A timeline runs along the time path the caller gives for a canvas: :meth:create_timelines answers one timeline per canvas, :meth:create_timeline the whole volume, its pages laid end to end.

Supports both IIIF Presentation API 2.x and 3.x formats. Time-based Presentation 3 canvases (duration without width/height) are read and expose their duration; they have no pixels, so no time path runs through them and the single-image accessors refuse a manifest whose first canvas is one.

Examples

>>> from timetoalign.testdata import ensure_data
>>> manifest = ensure_data("supra") / "image" / "ifff_manifest.json"
>>> loader = IIIFManifestLoader().load(manifest)
>>> loader.dimensions
{'width': 4096, 'height': 299400}

Individual canvases carry their own label and dimensions:

>>> for canvas in loader.manifest_info.canvases:
...     print(f"{canvas.label}: {canvas.width}x{canvas.height}")
display image: 4096x299400

A piano roll is read from top to bottom, so its time path is a vertical line down the middle of the image:

>>> from timetoalign.loader.graphical.paths import VerticalLinePath
>>> path = VerticalLinePath(x=2048, y0=0, y1=299400, tolerance=2048)
>>> (roll,) = loader.create_timelines(path)
>>> roll.length.value
299400

create_timeline

loader.graphical.IIIFManifestLoader.create_timeline(
    paths,
    *,
    canvases=None,
    uid=None,
    name=None,
    page_ids=None,
    accolade_ids=None,
)

Create the volume: the selected canvases laid end to end, in pixels.

Each selected canvas becomes one page along its time path, in manifest order, and the volume is the segment line of the pages, as long as all of them together. A page whose path is a :class:~timetoalign.loader.graphical.paths.PiecewisePath is itself a segment line of accolades, one per piece; any other path gives one plain timeline of the path’s length. See :meth:create_timelines for what a page and an accolade state.

The volume states the manifest it was read from as the property dcterms:source ({"id": <manifest id>}; a manifest without an id states nothing). This property is provisional: it may change.

Parameters

Name Type Description Default
paths Mapping[int | str, TimeAxisPath] | TimeAxisPath The time path of each selected canvas: a mapping from a canvas, named by its position from 0 (as :meth:get_canvas) or by its id, to its path; or one path, where exactly one canvas is selected. required
canvases Sequence[int | str] | None The canvases to read, by position or id; they are read in manifest order whatever order they are named in. None selects every canvas that states a width and a height. None
uid str | None The volume’s id. Minted (dgt_…) if None. None
name str | None The volume’s name. The manifest’s label if None. None
page_ids Sequence[str] | str | None The pages’ ids: a sequence, one per page, or a template filled with page and n ("p{page}"). Minted if None. None
accolade_ids Sequence[str] | str | None The accolades’ ids: a sequence over the whole call, or a template filled with page, accolade and n ("p{page}_s{accolade}"). Minted if None. None

Returns

Name Type Description
SegmentLine The locked volume: SegmentLine[SegmentLine[DiscreteGraphical | | | [SegmentLine](`timetoalign.timelines.SegmentLine`) | Timeline]] where the pages are built of accolades, else
SegmentLine SegmentLine[DiscreteGraphicalTimeline].

Raises

Name Type Description
RuntimeError If no manifest has been loaded.
TypeError If canvases is a bare string, or paths is neither a mapping nor a time path.
KeyError If canvases names a canvas the manifest does not hold, or paths names a canvas that is unknown, time-based or not selected.
ValueError If a selected canvas has no path, one path is given for several canvases, a line leaves its canvas, no canvas is selected, some pages are built of accolades and others are not, or an ids argument does not fit the call. Nothing is built then.

Examples

Two pages of a printed score, each with two systems::

from timetoalign.loader.graphical.paths import (
    HorizontalLinePath, PiecewisePath,
)

def systems(*lines):
    return PiecewisePath(tuple(
        HorizontalLinePath(x0=x0, x1=x1, y=y, tolerance=300)
        for x0, x1, y in lines
    ))

loader = IIIFManifestLoader().load("manifest.json")
volume = loader.create_timeline(
    {
        1: systems((1221, 4101, 1900), (971, 4112, 3300)),
        2: systems((519, 3661, 900), (522, 3659, 2300)),
    },
    canvases=[1, 2],
    uid="scan",
)
for _, offset, page in volume.iter_segments():
    print(page.name, offset.value, page.length.value,
          page.statements["dcterms:source"])

create_timelines

loader.graphical.IIIFManifestLoader.create_timelines(
    paths,
    *,
    canvases=None,
    page_ids=None,
    accolade_ids=None,
)

Create one timeline in pixels per selected canvas, along its time path.

A canvas whose path is a :class:~timetoalign.loader.graphical.paths.PiecewisePath becomes a segment line of accolades, one per piece in path order: an accolade along a horizontal piece is as long as the piece (x1 - x0) and states the strip it stands for in meta["box"]. Any other path gives one plain timeline of the path’s length, which must be a whole number of pixels: a piano roll is read along a VerticalLinePath.

Each page is named with its canvas’s label and states the canvas it measures: its id in meta["image"] (the accolades too) and as the property dcterms:source ({"id": <canvas id>}; Presentation 2 @id, Presentation 3 id). A canvas without an id states nothing. This property is provisional: it may change.

A horizontal or vertical line must lie on its canvas: 0 <= x0, x1 <= width and 0 <= y <= height (for a vertical line 0 <= x <= width, 0 <= y0 and y1 <= height).

Parameters

Name Type Description Default
paths Mapping[int | str, TimeAxisPath] | TimeAxisPath As :meth:create_timeline. required
canvases Sequence[int | str] | None As :meth:create_timeline. None
page_ids Sequence[str] | str | None As :meth:create_timeline. None
accolade_ids Sequence[str] | str | None As :meth:create_timeline. None

Returns

Name Type Description
list[DiscreteGraphicalTimeline | SegmentLine[DiscreteGraphicalTimeline]] The pages in manifest order, each locked; an empty list where no
list[DiscreteGraphicalTimeline | SegmentLine[DiscreteGraphicalTimeline]] canvas is selected.

Raises

Name Type Description
RuntimeError If no manifest has been loaded.
TypeError As :meth:create_timeline.
KeyError As :meth:create_timeline.
ValueError As :meth:create_timeline, except that no canvas need be selected and the pages need not be of one kind.

Examples

A piano roll, read from top to bottom::

from timetoalign.loader.graphical.paths import VerticalLinePath

loader = IIIFManifestLoader().load("manifest.json")
(roll,) = loader.create_timelines(
    VerticalLinePath(x=2048, y0=0, y1=299400, tolerance=2048)
)
