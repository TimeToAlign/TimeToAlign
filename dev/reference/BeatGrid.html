BeatGrid

timelines.BeatGrid(segments, *, extent=None)

A sequence of tempo segments and the beats they generate.

Segments are given as they are stated — typically without an end, each one generating beats forever. The grid puts them in time order and bounds each by the next one’s start; the last segment is bounded by extent, or generates without end when no extent is given.

Examples

>>> from fractions import Fraction
>>> grid = BeatGrid.from_tempo(120, extent=8)
>>> [str(beat.seconds) for beat in grid.iter_beats()][:5]
['0', '1/2', '1', '3/2', '2']
>>> grid.seconds_at(2)
Coordinate(2.0, seconds)
>>> grid.position_at(2.75).instant
Coordinate(2.5, seconds)
>>> grid.position_at(2.75).instant == grid.seconds_at(2, 2)
True

Attributes

Name Description
extent Exclusive bound of the grid in seconds, or None.
n_measures How many measures the grid’s beats fall into.
n_segments How many tempo segments the grid holds.
segments The segments in time order, each bounded by its successor.

Methods

export_to_csv Write the grid’s beats in an audio tool’s annotation format.

get_beat_table Render the grid’s beats as a table.
iter_beats Yield the grid’s beats in time order.

Build a single-segment grid from one tempo statement.

Return the beat sounding at seconds.

The beat whose span contains the position, that is the last beat at or before it.

Parameters

Name Type Description Default
seconds SecondsSpec A position on the grid’s seconds axis. required

Raises

Name Type Description

quarters_between

timelines.BeatGrid.quarters_between(start_seconds, end_seconds)

Integrate exact quarter-note length over a seconds interval.

Each segment contributes its own tempo. The domain is [0, extent] — [0, inf) on an unbounded grid — closed at both ends, so the extent itself may be named even though no beat sounds there. A grid that opens late still reads the seconds before it, at its first segment’s tempo: that stretch carries the anchor the floating-measure lattice hangs on. Outside the domain the grid states no tempo, and this raises rather than extrapolating, exactly as the seconds direction does.

Parameters

Name Type Description Default
start_seconds SecondsSpec Where the interval opens. required
end_seconds SecondsSpec Where the interval closes. required

Returns

Name Type Description
Fraction The interval’s length in quarter notes, exactly.

Raises

Name Type Description
ValueError If the interval runs backwards, or if either end lies outside the grid’s domain.

Return the instant of a measure and beat, in seconds.

Parameters

Name Type Description Default
measure int Measure number in the grid’s own numbering. required
beat int | float | Fraction Beat within that measure, 1-based. A fractional beat interpolates between the beats on either side of it. 1
policy BeatPolicy | None Read the beat index under this counting instead of the grid’s own lattice — the beat becomes a quarter-note offset from the downbeat, converted back through the segments’ tempi. None

Returns

Raises

Name Type Description
ValueError If the measure or beat is not one the grid states, or if the position falls outside the measure.
