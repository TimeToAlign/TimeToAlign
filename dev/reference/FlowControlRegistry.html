FlowControlRegistry

timelines.FlowControlRegistry(elements=(), *, unit=None, number_type=None)

The flow control of one timeline: its elements in canonical order.

One collection holds every :class:FlowControlElement, ordered by coordinate and then by ID; jumps, jump_targets, breaks, section_breaks and barlines are views of it by class. All of them are tuples: the collection changes through :meth:add, :meth:add_all, :meth:with_belief and :meth:with_beliefs alone, and no element ever leaves it. Every element carries an ID unique within the registry and, once the registry belongs to a timeline, within that timeline’s whole manifest: an element whose minted ID is taken is stored under a freshly minted ID, and one whose given ID is taken is refused. A manifest writes the registry as the timeline’s flow_control array.

The registry refuses what cannot be played: a second Jump at a coordinate, a to naming neither a :class:JumpTarget of the registry nor a place of its timeline, an after that does not name exactly one destination of another Jump of the registry, and an element or a destination’s place lying outside the axis, which runs from 0 to the timeline’s length (from 0 on while that length is unknown, and for a registry that belongs to no timeline).

An element that some actor believes "false" is rejected (:attr:FlowControlElement.is_rejected, :meth:with_belief): it stays in the registry and is written, but it is out of every rule, as what is checked and as what is named. A rejected Jump and its replacement may therefore share a coordinate. An element that another element not rejected names (by to or after) is not rejected alone: the elements naming it are rejected in the same step (:meth:with_beliefs).

Parameters

Name Type Description Default
elements Iterable[FlowControlElement] The elements the registry starts with, added together. ()
unit TimeUnit | str | None The unit of the axis the registry is bound to, if any. None
number_type NumberType | str | None The number type of that axis, if any. None

Attributes

Name Type Description
unit TimeUnit | None The unit of the axis the registry is bound to, if any.
number_type NumberType | None The number type of that axis, if any.

Examples

>>> from timetoalign.core import Coordinate, TimeUnit
>>> registry = FlowControlRegistry(unit=TimeUnit.quarters)
>>> registry.add(JumpTarget(Coordinate(16, "quarters"), id="segno"))
JumpTarget('segno' @ 16 quarters)
>>> registry.add(
...     Jump(
...         Coordinate(64, "quarters"),
...         [JumpDestination(to="segno", repeat_count=1, reset=False)],
...     )
... ).id
'jump_1'
>>> [element.role for element in registry.elements]
['jump_target', 'jump']
>>> registry.place_of(registry.jumps[0].targets[0], registry.jumps[0])
Coordinate(Fraction(16, 1), quarters)

active_elements

timelines.FlowControlRegistry.active_elements(
    believer=None,
    beliefs=DEFAULT_BELIEFS,
    context=None,
)

Return the elements that are read as flow control, in canonical order.

Without a believer these are the elements not rejected: every element but those some actor believes "false" (:attr:FlowControlElement.is_rejected). A believer narrows the reading to that actor’s beliefs: the belief filter of :func:~timetoalign.core.provenance.belief_mask, read on each element’s provenance, where an element without provenance, or without a belief of the believer’s, is one the believer has not decided on, and one the believer holds two beliefs in (in two entries) is read as the more critical of them.

Parameters

Name Type Description Default
believer str | None The actor whose beliefs alone decide; None leaves out what any actor rejects. None
beliefs Collection[BeliefState] With a believer, the belief states kept; every state but "false" by default. DEFAULT_BELIEFS
context Mapping[str, Any] | None The JSON-LD context under which actors compare as IRIs. None

Raises

Name Type Description
ValueError If beliefs is no collection of belief states.

Examples

>>> from timetoalign.core import Coordinate
>>> registry = FlowControlRegistry(unit="quarters")
>>> barline = registry.add(Barline(Coordinate(8, "quarters")))
>>> _ = registry.with_belief(barline.id, "ana", "false", date="2026-11-25")
>>> registry.elements, registry.active_elements()
((Barline('barline_1' @ 8 quarters),), [])
>>> registry.active_elements(believer="bea")
[Barline('barline_1' @ 8 quarters)]

timelines.FlowControlRegistry.add_all(elements)

Add several elements together, or none of them.

The elements may name one another in any order. An element whose minted ID is taken is stored under a freshly minted ID, and the elements added with it name it by that ID.

Parameters

Name Type Description Default
elements Iterable[FlowControlElement] The elements. required

Returns

Name Type Description
list[FlowControlElement] The stored elements in the order given, each with its
list[FlowControlElement] coordinate on the registry’s axis and its ID as admitted.

Raises

Name Type Description

from_dict

timelines.FlowControlRegistry.from_dict(
    data,
    *,
    unit,
    number_type=None,
    places=None,
)

Restore a registry bound to a timeline’s axis from its flow_control.

Each element of the array states its role (jump, jump_target, break, section_break or barline), its coordinate a bare value on the axis that unit and number_type (the unit’s own when None) describe. The elements are added together, in any order the array lists them. Keys the library does not know are kept on each element and written back.

Parameters

Name Type Description Default
data list[dict[str, Any]] The flow_control array. required
unit TimeUnit | str The axis’s unit. required
number_type NumberType | str | None The axis’s number type, or None for the unit’s own. None
places Mapping[str, Coordinate] | None The places of the timeline a destination may name beside the array’s jump targets: the starts of its Regions and of its child timelines and its own, by ID. None

Raises

Name Type Description
ValueError If the array or an element is malformed, an element is written in the form with type and target, or the registry refuses the elements.

place_of

timelines.FlowControlRegistry.place_of(destination, jump, *, elements=None)

Return where destination of jump goes on.

by is added to the Jump’s coordinate. to is the coordinate of the JumpTarget of that ID, else the place of that ID the registry’s timeline gives (the start of a Region or of a child timeline, or the timeline’s own start). A destination without place goes on at the nearest section break before the Jump, or at 0.

Parameters

Name Type Description Default
destination JumpDestination The destination. required
jump Jump The Jump holding it. required
elements Sequence[FlowControlElement] | None The elements to find jump targets and section breaks among; the elements not rejected (:meth:active_elements) when None. None

Raises

Name Type Description
KeyError If to names nothing, or a rejected jump target.

to_dict

timelines.FlowControlRegistry.to_dict(minimal=True)

Return the elements as the flow_control array.

Each element is written as its own object, in canonical order whatever order the elements were added in: by coordinate, then by ID, values compared exactly and IDs by Unicode code point. Nothing is written that the registry does not hold.

Parameters

Name Type Description Default
minimal bool Write each element in the minimal form (the default): every key at its default value left out, in the destinations of a Jump too. With False, the complete form: name, label and meta of every element and determined, reset and label of every destination are written whatever they hold. A key without a default (manifestation, ends, provenance, to, by, passes, repeat_count, after) is written only when stated. True

with_belief

timelines.FlowControlRegistry.with_belief(
    element_id,
    actor,
    belief,
    *,
    date=None,
    note=None,
    context=None,
)

Record actor’s belief in the element element_id.

The registry holds the element’s copy whose provenance records the belief (:meth:FlowControlElement.with_belief) in its place; the element’s ID, coordinate and every other key stay. The belief "false" rejects the element, which is how flow control is repaired: the wrong element is rejected and another one added, never changed or removed.

What names a rejected element would name nothing. An element that another element not rejected names, by a to or an after, is therefore not rejected alone: :meth:with_beliefs rejects it together with the elements naming it, and their replacements are added afterwards.

Parameters

Name Type Description Default
element_id str The element’s ID. required
actor str Who holds the belief, an IRI. required
belief BeliefValue "true", "false" or "unlikely". required
date str | datetime.date | None The day, YYYY-MM-DD or a :class:datetime.date; today when None. None
note str | None A remark. None
context Mapping[str, Any] | None The JSON-LD context under which actors compare as IRIs; None declares no prefix. None

Returns

Name Type Description
FlowControlElement The element as the registry holds it now.

Raises

Name Type Description
KeyError If the registry holds no element element_id.
ValueError As :meth:with_beliefs. Nothing has changed then.

Examples

>>> from timetoalign.core import Coordinate
>>> registry = FlowControlRegistry(unit="quarters")
>>> wrong = registry.add(
...     Jump(Coordinate(16, "quarters"), [JumpDestination(repeat_count=1)]))
>>> registry.with_belief(wrong.id, "ana", "false").is_rejected
True
>>> registry.add(
...     Jump(Coordinate(16, "quarters"), [JumpDestination(by=-8, repeat_count=1)])
... ).id
'jump_2'
>>> registry.jump_at(16).id
'jump_2'

with_beliefs

timelines.FlowControlRegistry.with_beliefs(
    element_ids,
    actor,
    belief,
    *,
    date=None,
    note=None,
    context=None,
)

Record actor’s belief in several elements in one step, or in none.

As :meth:with_belief for each element, the result checked as a whole: with the belief "false", an element and the elements naming it are rejected together, which neither could be alone.

Parameters

Name Type Description Default
element_ids Iterable[str] The elements’ IDs. required
actor str Who holds the belief, an IRI. required
belief BeliefValue "true", "false" or "unlikely". required
date str | datetime.date | None The day, YYYY-MM-DD or a :class:datetime.date; today when None. None
note str | None A remark. None
context Mapping[str, Any] | None The JSON-LD context under which actors compare as IRIs; None declares no prefix. None

Returns

Name Type Description
list[FlowControlElement] The elements as the registry holds them now, in the order given.

Raises

Name Type Description
KeyError If the registry holds no element of one of the IDs.
ValueError If the belief or the date is invalid; an element rejected by the step is named, by a to or an after, by an element that is not rejected after it; or an element no longer rejected by the step cannot be played among the elements not rejected (:meth:add_all). Nothing has changed then.

Examples

>>> from timetoalign.core import Coordinate
>>> registry = FlowControlRegistry(unit="quarters")
>>> segno, leap = registry.add_all([
...     JumpTarget(Coordinate(4, "quarters"), id="segno"),
...     Jump(Coordinate(16, "quarters"), [JumpDestination(to="segno")], id="ds"),
... ])
>>> registry.with_belief("segno", "ana", "false")
Traceback (most recent call last):
...
ValueError: jump_target 'segno' is not rejected alone: jump 'ds' names it. Reject the elements naming it in the same step (with_beliefs), then add their replacements
>>> [e.is_rejected for e in registry.with_beliefs(["segno", "ds"], "ana", "false")]
[True, True]
