Package

alignment.Package(id=None, name=None)

A TimeToShare package: a folder of manifests sharing their tables.

package.yaml at the folder’s root lists the package’s manifests and its tables: the registry (registry.parquet at the root, as this class writes it: one Parquet file holding every row, the non-event rows, one per manifest element, MatchClaim and parse, then the event rows, one per event, each position on the axis of its timeline’s root), the Parse table (tables/parses.parquet), one pre-parsed table per kind of event (tables/<Kind>/, each event’s content keyed by its ID, without positions) and the MatchClaim table (tables/MatchClaim/). A manifest names the registry and the MatchClaim table in its resources, with the timelines whose rows it keeps; nothing in a file names a manifest. An event ID is held once among all events of the package, every kind; a MatchClaim ID once among its MatchClaims; a timeline ID, as this class writes a package, by one manifest.

:meth:from_file opens a package; :meth:bundle reads one of its manifests as an :class:~timetoalign.alignment.AlignmentBundle, every table filtered by the timelines its resources list and the events’ content read when first asked for. :meth:write_bundle writes a bundle into the package as one of its manifests, and :meth:to_file writes a new package where it is told.

Parameters

Name Type Description Default
id str | None The package’s IRI where it is published (its repository or DOI), or None. None
name str | None Its human-readable name, or None. None

Examples

>>> import tempfile
>>> from fractions import Fraction
>>> from pathlib import Path
>>> from timetoalign.alignment import AlignmentBundle, Package
>>> from timetoalign.timelines import ContinuousLogicalTimeline
>>> score = ContinuousLogicalTimeline(length=Fraction(4), uid="score")
>>> _ = score.add_events(
...     [{"id": "n1", "event_type": "Note", "start": 0, "name": "C4"}]
... )
>>> bundle = AlignmentBundle(id="piece")
>>> _ = bundle.add_timeline(score)
>>> package = Package(name="Pieces")
>>> package.write_bundle(bundle, "piece.tts.yaml")
>>> path = package.to_file(Path(tempfile.mkdtemp()) / "package.yaml")
>>> package.manifests
['piece.tts.yaml']
>>> [(table["type"], table["url"]) for table in package.tables]
[('Registry', 'registry.parquet'), ('Parse', 'tables/parses.parquet'), ('Note', 'tables/Note/')]
>>> read = Package.from_file(path).bundle("piece.tts.yaml")
>>> read.get_timeline("score").events.table.column("id").to_pylist()
['n1']

bundle

alignment.Package.bundle(url)

The manifest at url as an :class:~timetoalign.alignment.AlignmentBundle.

Read as :meth:AlignmentBundle.from_file <timetoalign.alignment.AlignmentBundle.from_file> reads a manifest that package.yaml lists: every table its resources name, a single file as a folder, is read filtered, its rows of the timelines the resource lists (a MatchClaim’s either of whose timelines it lists), the other manifests’ passed over; each event’s content is read from its pre-parsed table, by ID, when its family’s events are first read. A manifest read alone instead refuses a row of a timeline it lacks in a single file.

Parameters

Name Type Description Default
url str The manifest’s URL as :attr:manifests lists it. required

Raises

Name Type Description
KeyError If the package lists no manifest at url, naming those it lists.
ValueError If the manifest is not written yet, or as AlignmentBundle.from_file refuses it.

from_file

alignment.Package.from_file(path)

Open the package whose package.yaml lies at path.

The file is read in any serialization of the format and validated (:func:timetoshare.validate_package); its manifests and tables are read when asked for (:meth:bundle). A file a write cut short left hidden beside the registry (its name with one or two . before it) or in a folder of tables/ (a name starting with . and ending in .parquet), which no reader reads, is removed.

Raises

Name Type Description
FileNotFoundError If no file lies at path.
timetoshare.SchemaValidationError If the file is no valid package.yaml.

to_file

alignment.Package.to_file(path)

Write the package: every bundle staged, then package.yaml.

package.yaml is written in canonical YAML, every manifest listed explicitly and one table entry per type folder. Every bundle staged is written in one go: one new file per type, holding the rows of them all (:meth:write_bundle). Once written, the package is checked whole (:func:timetoshare.tables.package_problems), and its first problem is raised.

A refusal leaves the package as it was: on disk, every file rewritten gets its bytes back and every file and folder created is removed, package.yaml included; in memory, a new package stays unwritten with its bundles staged.

Parameters

Name Type Description Default
path str | os.PathLike[str] The package.yaml of a new package, in a folder holding none yet; a package opened or written before is written where it lies. required

Returns

Name Type Description
Path The path written.

Raises

Name Type Description
ValueError If path is not named package.yaml, a new package would be written over a file lying there, a package lying elsewhere would be written at path, an opened package is of another format version, or the package check finds a problem.

write_bundle

alignment.Package.write_bundle(bundle, url)

Write bundle into the package as its manifest at url.

The manifest lies at url under the package’s root, its resources naming the registry (registry.parquet at the package’s root, or where package.yaml places it, relative to the manifest, without size or digest, since other manifests’ rows share it) with the timelines holding its events, and the MatchClaim table (tables/MatchClaim/) with the timelines its MatchClaims name; a resource that is no table (a recording) is kept. A table the bundle carries (a table resource of a type it does not read, or a MatchClaim table it holds no rows of) is copied into the package with its bytes, at tables/<Type>/ under its own name (a name holding other content: one seeded from the table’s content), listed in package.yaml, and its resource names the copy; one lying in the package already stays where it lies, and equal content lying at its name is that copy. The format reads such a table as the pre-parsed table of its type, keyed by id: a Parquet table without an id column of strings is the package check’s foreign_table, so writing the package raises it and restores the package, while a folder holding no Parquet file (scans, recordings) is carried. A table resource of a type the bundle holds no rows of and does not carry is refused: the writer has no file to copy.

Its events of every kind (:func:~timetoalign.timelines.manifest.event_tables) go into the registry, one file holding the rows of every manifest, rewritten whole with each write in the order of the format (timetoshare.tables.write_registry: the non-event rows by location and id, then the event rows by timeline_id, exact start and id). Their parses go into the Parse table (tables/parses.parquet, each parse once, its source written as a path from the package’s root where the file lies under it, else as its file: URI, so that the package names no path of the machine that wrote it; read back, the source is the file’s path again), their content into the pre-parsed table of their kind and their MatchClaims (each row with its own provenance) into the MatchClaim table: each write adds one new file per kind and one of MatchClaims, tables/<Type>/part_<13 base-36 characters>.parquet, holding the rows of every bundle it writes (:meth:to_file writes every bundle staged at once), named from its content through the library’s ID minter, so that a rebuild names its files again; a column two bundles hold in two types is held in the one type holding both exactly (an int8 and an int64 column as int64), never in a type that may change a value. Last, the registry’s non-event rows are written from the manifests and tables (timetoshare.tables.write_non_event_rows, which rewrites the registry whole once more, its event rows kept). A manifest the package holds at url already is replaced: the rows of its timelines and of the bundle’s leave the files holding them (a pre-parsed row by the ID of its event), each such file rewritten whole (one left without a row removed), the other manifests’ rows kept; its MatchClaims must be kept by the bundle, as :meth:MatchClaimField.to_parquet <timetoalign.alignment.MatchClaimField.to_parquet> requires, so a bundle holding none while the package holds MatchClaims of that manifest is refused, and a parse once written stays in the Parse table.

Before anything is written, every ID is checked in memory: each event ID among every event of the package, every kind; each MatchClaim ID among its MatchClaims; each timeline ID among the timelines of its other manifests. A collision is refused, naming the ID and both holders; nothing is renamed. A new package (not written yet) stages the bundle, which :meth:to_file writes: the bundle’s own IDs are checked against an index of the IDs staged, so staging N bundles costs in the number of their rows. A package lying on disk (:meth:from_file, or written by :meth:to_file) is written at once, package.yaml with it, and each call reads the id and timeline columns of every file of the package, rewrites every file holding a row of the manifest replaced, and checks the package whole (:func:timetoshare.tables.package_problems): its cost grows with the package, so a package of many manifests is built new, staging every bundle and writing them with one :meth:to_file. Once written, the bundle’s :attr:resources <timetoalign.alignment.AlignmentBundle.resources> are the manifest’s, and the tables it carries the package’s copies.

A refusal leaves the package as it was, on disk and in memory: what can be checked in memory is checked before any file is written (the IDs, the bundle’s resources, an opened package’s format version); the new files are written under names readers skip and renamed into place once the old rows are removed; and where the write or the package check after it fails, every file rewritten gets its bytes back, every new file is removed. This holds for an exception, not for a process killed between the removal of the old rows and the renaming of the new files: the package then lacks the rows of the manifests written, until they are written again (:meth:from_file removes the new files left hidden).

Parameters

Name Type Description Default
bundle AlignmentBundle The bundle. required
url str The manifest’s location relative to the package’s root, such as bach.tts.yaml. required

Raises

Name Type Description
ValueError If url leaves the package’s root or names no file in it, an ID collides, the bundle cannot be written as a manifest, names a table of a type it holds no rows of that it does not carry or whose file no longer lies where it was read (the writer has nothing to copy), or its MatchClaims do not keep the ones the package holds for it, or an opened package is of another format version or names a folder for its registry, before anything is written; if the package check refuses the package written, with everything restored.
