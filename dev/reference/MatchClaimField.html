MatchClaimField

alignment.MatchClaimField(
    raw=None,
    *,
    source_fields=None,
    name=None,
    provenance=None,
)

The MatchClaim table: a SemanticField[MatchClaim] columnar store.

MatchClaimField is the Field paired with the :class:MatchClaim scalar. It holds a large set of MatchClaims (millions of rows) as Arrow columns instead of one frozen :class:MatchClaim per claim; individual claims are materialised lazily, only when a row is indexed or iterated. Every kind of MatchClaim is a row like any other: synchronous claims with their anchors, NOMATCH and conceptual claims without.

Like every paired Field, its struct schema is derived from the scalar by :func:~timetoalign.core.fields.derive_arrow_struct — so a row’s type is exactly MatchClaimField.pa_schema. Its :attr:table (and the Parquet file :meth:to_parquet writes, match_claims.parquet) has one column per top-level property of :class:MatchClaim, each nested as the property is. A provenance shared by every row is held once at field level (or None) and injected on read: the provenance column is left null, and :meth:__getitem__ gives each materialised claim the field’s provenance. Claims whose provenance differs, given to :meth:from_claims, carry it per row.

A MatchClaim is addressed by its id alone: an id held twice is refused, and an id never changes. A field mints no id: a row without one keeps it missing until the :class:~timetoalign.alignment.bundle.AlignmentBundle it joins mints it.

Attributes

Name Type Description
table pa.Table The claims as a :class:pyarrow.Table (read-only property), one column per MatchClaim property.
provenance Provenance | None Shared :class:~timetoalign.core.provenance.Provenance (or None) applied to every materialised claim.

Examples

>>> field = MatchClaimField.from_columns(
...     timeline_a_ids=["A", "A", "B"],
...     timeline_b_ids=["B", "C", "C"],
...     event_a_ids=["a1", "a1", "b1"],
...     event_b_ids=["b0", "c0", "c1"],
...     coordinate_a=[0, 0, 1],
...     coordinate_b=[10.0, 20.0, 21.0],
...     timelines={
...         "A": ("quarters", "fraction"),
...         "B": ("seconds", "float"),
...         "C": ("seconds", "float"),
...     },
...     provenance=Provenance(service="https://example.org/aligner"),
... )
>>> len(field)
3
>>> field[0].timeline_a_id, field[0].timeline_b_id
('A', 'B')

at

alignment.MatchClaimField.at(timeline_id, coordinate)

Return claims relevant at (timeline_id, coordinate).

The selection is a vectorized PyArrow boolean mask over the struct column. Instant rows compare their start coordinate exactly. Interval rows use closed containment between their start and end coordinates. Rows without anchors (NOMATCH, conceptual) are never relevant. No claim is materialised and the rest of the field is never touched; the shared provenance carries over.

Coordinate matching is exact in the query coordinate’s declared number representation. There is no tolerance or nearest-value fallback.

connects_groups

alignment.MatchClaimField.connects_groups(group_a_ids, group_b_ids)

Whether any synchronous claim spans the two given sets of timeline ids.

True when at least one row with anchors has one side in group_a_ids and the other side in group_b_ids; a NOMATCH or conceptual row states no temporal equivalence and connects nothing. The test is a vectorized mask reduced with :func:pyarrow.compute.any; no claim is materialised, so it answers commensurability over a million-row field in one pass.

filter

alignment.MatchClaimField.filter(
    timeline_id=None,
    timeline_ids=None,
    id_pattern=None,
    between=None,
    within=None,
    synchronous_only=False,
    nomatch_only=False,
    believer=None,
    beliefs=DEFAULT_BELIEFS,
    context=None,
)

Return a filtered view following the unified filter API.

Every criterion is a vectorized boolean mask over the claim columns; no claim is materialised and the shared provenance carries over. All non-default criteria are combined with logical AND.

include_domains / include_units are deliberately absent: they need per-timeline metadata (domain, unit) that this store does not hold. A caller that owns that metadata — an :class:~timetoalign.alignment.bundle.AlignmentBundle, say — resolves them into the set of timeline ids that pass and hands that set to within.

from_claims

alignment.MatchClaimField.from_claims(claims, *, provenance=None)

Build a field from existing :class:MatchClaim objects.

Every kind of claim is a row: synchronous claims with their anchors (interval claims with both), NOMATCH and conceptual claims without. Each row keeps every property of its claim, so every claim materialises equal to the one stored. A MatchClaim is addressed by its id alone: two claims under one id are refused (an id is never renamed), and a claim without an id keeps it missing (the bundle the field joins mints it).

If provenance is None and all claims share one equal :class:~timetoalign.core.provenance.Provenance, it is adopted as the field-level provenance and the rows carry none. If the claims’ provenance differs (None included), the field’s stays None and each row carries its own claim’s.

Parameters

Name Type Description Default
claims Sequence[MatchClaim] The claims to store. required
provenance Provenance | None Explicit field-level provenance. When provided it replaces every claim’s own. None

Returns

Name Type Description
'MatchClaimField' A new :class:MatchClaimField.

Raises

Name Type Description
ValueError If two claims hold the same id, or an anchor holds a coordinate no cell can hold (a non-finite number), which every reader of the MatchClaim table refuses.

from_columns

alignment.MatchClaimField.from_columns(
    timeline_a_ids,
    timeline_b_ids,
    event_a_ids,
    event_b_ids,
    coordinate_a,
    coordinate_b,
    *,
    timelines,
    end_coordinate_a=None,
    end_coordinate_b=None,
    certainty=1.0,
    provenance=None,
)

Build a field of event matches from parallel columns (the vectorized path).

This is the constructor a bulk producer (e.g. an alignment loader) uses. It assembles the derived MatchClaim struct array straight from the parallel inputs and never materialises a single :class:MatchClaim Python object, so it scales to millions of rows.

Each row is a synchronous claim between two events: the timeline and event ids are filled from the inputs, and every coordinate is a position on its row’s timeline, written in that timeline’s unit and declared number type. With the two end columns, every row with an end on both sides is an interval claim. The ids are left null: the bundle the field joins mints them (:meth:~timetoalign.alignment.bundle.AlignmentBundle.add_match_claim_field), so fields of several sources join one bundle. Names are left null, and so is the provenance column (the shared provenance is injected on read). The field is checked against the timelines (:meth:check_on_timelines).

Parameters

Name Type Description Default
timeline_a_ids Sequence[str] | pa.Array | pa.ChunkedArray Timeline-A ids, one per claim. required
timeline_b_ids Sequence[str] | pa.Array | pa.ChunkedArray Timeline-B ids, one per claim. required
event_a_ids Sequence[str] | pa.Array | pa.ChunkedArray The event on timeline A, one per claim. required
event_b_ids Sequence[str] | pa.Array | pa.ChunkedArray The event on timeline B, one per claim. required
coordinate_a Sequence[int | float | Fraction] | pa.Array | pa.ChunkedArray The position of the event on timeline A. required
coordinate_b Sequence[int | float | Fraction] | pa.Array | pa.ChunkedArray The position of the event on timeline B. required
timelines Iterable[Any] | Mapping[str, Any] Every timeline the rows name: timelines, or a mapping from a timeline id to a timeline or its (unit, number_type) pair. required
end_coordinate_a Sequence[int | float | Fraction | None] | pa.Array | pa.ChunkedArray | None The end of each event on timeline A (null on both sides for an instant claim). None
end_coordinate_b Sequence[int | float | Fraction | None] | pa.Array | pa.ChunkedArray | None The end of each event on timeline B. None

provenance Provenance | None Shared provenance for every claim in the field. None

from_dict

alignment.MatchClaimField.from_dict(data)

Deserialize a field from a plain dictionary (inverse of :meth:to_dict).

The mapping holds provenance (the field’s :meth:~timetoalign.core.provenance.Provenance.to_dict, or None) and rows: one mapping per claim whose keys are the :attr:table’s columns. Each coordinate is a coordinate dict ({unit, number_type, value}), read by :func:~timetoalign.core.retrieval.coordinate_from_dict and written into its storage cell as :meth:from_claims writes a claim’s; every other cell is read as stored. A field built from claims therefore comes back with an equal table and equal claims.

from_table

alignment.MatchClaimField.from_table(table)

Read a field back from its Arrow table (inverse of :attr:table).

The table must hold one column per top-level property of :class:MatchClaim, named and typed as the fields of :attr:pa_schema; the columns are read by name, in any order, and may be chunked, as they are when the table was read from Parquet. Further columns (any other name, such as a scope column a package written by an earlier tool holds) are kept as they stand, after the properties, and never read: :attr:table and the file :meth:to_parquet writes hold them again, and the field’s own queries carry them row for row. The field-level provenance travels in the table’s schema metadata under TimeToShare’s key timetoshare:provenance (the JSON of :meth:~timetoalign.core.provenance.Provenance.to_dict); a table without that key gives a field whose provenance is None. Every row is kept as stored; a row without an id keeps none (the bundle it joins mints it).

Parameters

Name Type Description Default
table pa.Table A table as written by :attr:table. required

Returns

Name Type Description
'MatchClaimField' A new :class:MatchClaimField.

Raises

Name Type Description
ValueError If the table lacks a column of a MatchClaim property, or a column’s type is not the property’s; if a row is not a MatchClaim (:meth:_read); if the table carries provenance both in its schema metadata and in its rows; or if two rows hold the same id (a MatchClaim is addressed by its id alone).

Materialise every row into a list of :class:MatchClaim objects.

Returns

Name Type Description

to_dict

alignment.MatchClaimField.to_dict()

Render the :attr:table as a plain dictionary (inverse of :meth:from_dict).

{"provenance": ..., "rows": [...]}: the field’s provenance (:meth:~timetoalign.core.provenance.Provenance.to_dict, or None) and one mapping per claim whose keys are the table’s columns. A coordinate cell is written as a coordinate dict (:func:~timetoalign.core.retrieval.coordinate_to_dict: unit, number_type, value, a Fraction as [numerator, denominator]), the value the materialised claim holds, as :meth:MatchClaim.to_dict writes it; every other cell as stored, a nested property a nested mapping. Every value is a string, number, boolean, None, mapping or list, so the dictionary can be written as JSON or YAML.

Returns

Name Type Description
dict[str, Any] A round-trippable mapping.

Examples

>>> field = MatchClaimField.from_columns(
...     ["score"], ["audio"], ["n1"], ["o1"], [Fraction(1, 3)], [0.5],
...     timelines={
...         "score": ("quarters", "fraction"),
...         "audio": ("seconds", "float"),
...     },
... )
>>> row = field.to_dict()["rows"][0]
>>> row["start_anchor"]["coordinate_a"]
{'unit': 'quarters', 'number_type': 'fraction', 'value': [1, 3]}
>>> row["start_anchor"]["coordinate_b"]
{'unit': 'seconds', 'number_type': 'float', 'value': 0.5}
>>> row["id"], row["end_anchor"]
(None, None)

to_parquet

alignment.MatchClaimField.to_parquet(path)

Write the MatchClaim table to its Parquet file.

The file holds :attr:package_table (each anchor coordinate’s number written once, by its number type), the field-level provenance in its schema metadata, so :meth:from_parquet reads back every value exactly; further columns of a table read follow the properties (:meth:from_table). Where the file exists, the new table must succeed it: every MatchClaim of the existing table, by its id, is in this one, with the same timelines, events, anchors and every other value; only its provenance may differ (a MatchClaim is never removed and never changed, only believed or disbelieved). The file is replaced whole, never in part: a write that fails leaves the file as it was and no temporary file.

Every MatchClaim written holds an id, which a named MatchStamp may record: a field whose rows hold none (built from columns or from claims without ids) is written from the bundle it joined, which minted them (:attr:AlignmentBundle.match_claim_table <timetoalign.alignment.bundle.AlignmentBundle.match_claim_table>).

Parameters

Name Type Description Default
path str | os.PathLike[str] The file, or a directory to hold :attr:file_name (match_claims.parquet). required

Returns

Name Type Description
Path The path of the file written.

Raises

Name Type Description
ValueError If a row holds no id, or the existing table holds a MatchClaim this one lacks or changes.

with_belief

alignment.MatchClaimField.with_belief(claim_id, belief, *, context=None)

A copy of the table whose MatchClaim claim_id holds belief.

Only that row’s provenance changes, as :meth:MatchClaim.with_belief changes a claim’s; every other row, and every other column, is kept. A provenance the field holds once for every row stays shared where the field has one row; otherwise every row then carries its own, since one row’s differs.

Returns

Name Type Description
'MatchClaimField' The new field; this one is left as it is.

Raises

Name Type Description
KeyError If no row holds claim_id.
