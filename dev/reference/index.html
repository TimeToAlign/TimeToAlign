API Reference

Core Types

Fundamental types for coordinates, units, domains, and cross-section timestamps.

Coordinate A position on a timeline, defined by a value and unit.
CoordinateField Semantic field for coordinate fields.
Coord
CoordinateSpec
CoordinateValue
IdCoordinate A Coordinate that carries the ID of the timeline it belongs to.
Interval A non-decreasing interval between two plain coordinates.
IntervalField Semantic field storing intervals with shared axis metadata.
Point A point of an image: its x and y, on one axis.
PointField Paired Field for :class:Point: {x, y} on one declared axis.
Shape An area of an image, on one axis: a :class:BoundingBox or a
ShapeField The field of one kind of shape: every number on one declared axis.
BoundingBox An axis-aligned box of an image: x, y, width, height.
BoundingBoxField Paired Field for :class:BoundingBox: {x, y, width, height}.
Quadrilateral A four-cornered area of an image, its corners in the canonical order.
QuadrilateralField Paired Field for :class:Quadrilateral: four corners of {x, y}.
Event An event of a timeline: its ID and its position on the timeline’s axis.
EventField Paired Field for :class:Event: {id, start, duration} on one axis.
Box An area of an image as an interval event of a timeline along its x.
BoxField Paired Field for :class:Box: every number on one declared axis.
Note A single note or rest event.
NoteField Paired Field for :class:Note: every position on one axis, declared once.
ScoreNote A note or rest of a score: a :class:Note written on a staff, in a voice.
ScoreNoteField Paired Field for :class:ScoreNote.
OptionalCoordinate
ResolvedCoordinate Decomposed form of a CoordinateSpec input.
resolve_coordinate_spec Decompose a coordinate specification without converting its unit.
Domain The temporal domain of a timeline.
TimeUnit Units of measurement for coordinates.
NumberType The numeric type used for coordinate values.
EventType Whether an event is an instant or interval.
ColumnNaming How to name columns in timestamp DataFrames.
ColumnRole Semantic role of a column in the table.
ScopedId An identifier with a scope prefix and local part.
TimeStamp A synchronized instant across a timeline hierarchy.
TimeIntervalStamp A synchronized collection of canonical typed timeline intervals.

Timelines

Timeline classes for all six domain/modality combinations.

Timeline A positive coordinate axis with events and nested child timelines.
ContinuousLogicalTimeline A logical timeline with continuous coordinates.
DiscreteLogicalTimeline A logical timeline with discrete (integer) coordinates.
ContinuousPhysicalTimeline A physical timeline with continuous coordinates.
DiscretePhysicalTimeline A physical timeline with discrete (integer) coordinates.
ContinuousGraphicalTimeline A graphical timeline with continuous coordinates.
DiscreteGraphicalTimeline A graphical timeline with discrete (integer) coordinates.
LogicalTimeline A timeline representing logical/musical time.
PhysicalTimeline A timeline representing physical/acoustic time.
GraphicalTimeline A timeline representing graphical/spatial coordinates.
SegmentLine A timeline whose cached parameterized classes inherit the segment API.
MeasureMap An immutable sequence of measures in printed order.
UnknownLengthError An operation needs the end of a timeline whose length is unknown.

Beat Grids

Tempo segments that generate a labelled lattice of beats on a seconds axis.

BeatGrid A sequence of tempo segments and the beats they generate.
BeatGridSegment One tempo segment of a beat grid: an anchor beat and how it repeats.
GridBeat One beat of a grid, labelled in both numbering schemes.
BeatPolicy How a bar is counted in beats: a grouping cycle over one division.

Flow Control

The elements of a timeline’s flow control, the engine that plays them, FlowMaps over the stretches of a root timeline, and virtual timelines.

FlowControlRegistry The flow control of one timeline: its elements in canonical order.
FlowControlElement What the five kinds of flow-control element share.
Jump Where the flow may leave the axis, and every place it may go on at.
JumpDestination One place a Jump may go on at, and when it does.
JumpTarget A place a destination names: a repeat start, a segno, a coda, a bracket.
Break A place the flow never goes on across.
SectionBreak Where a section ends: a movement boundary, a section of a piece.
Barline A barline the source prints: a double or a final barline.
FlowCondition When a destination is taken, or a Break ends the flow.
DestinationReference One destination of a Jump, named by that Jump and its place.
PassesFrom The passes from the first on: {from: n} in a manifest.
play Play flow control over an axis of length.
atomic_sections Return the stretches of the axis that flow control never divides.
FlowResult A flow: what is played, in order.
FlowFinding Something playing flow control found.
AtomicSection A stretch of the axis that flow control never divides.
PlayedFlow The flow a timeline’s flow control plays, and what playing it found.
FlowMap One order in which stretches of one root timeline are played.
ResolvedFlowMap A played order as stretches of a root timeline’s axis, placed in order.
PlacedChunk A stretch of the root timeline, placed on the virtual axis.
PlacedGap A stretch of the virtual axis that nothing of the root fills.
VirtualTimeline The statement that a map was applied to a timeline, giving a timeline.
ComputedFlows What computing a timeline’s flows from its flow control wrote.
StatedFlow What writing the order of measures a source states wrote.
Gap A stretch of a played order that nothing of the timeline fills.
FlowManifestation What a flow-control element looks like in the score.
FlowConvention How flow control is played into a flow.
FlowFindingKind What playing flow control found.
MeasureFindingKind What a look at a score’s measures found about their flow control.
FlowControlDraft Flow control being written from a score, before it joins a registry.
MeasureRange A right-open range of measure counts, as a .flow.csv row states one.
MeasureFinding Something a look at the measures found about their flow control.
flow_control_from_measures Return the flow control a measure map states.
measure_keys_from_flow_control Return the row keys that flow control states, one object per measure.
measure_order_from_successors Walk the successors a source states into the order of measures they give.
measure_ranges State stretches of the axis as right-open ranges of measure counts.
read_flow_csv Read a .flow.csv file: the measure-count ranges of each flow.
repeat_end_findings Find the repeat ends whose repeat would begin right behind a last bracket.

Conversion Maps

Functions for transforming coordinates between units.

ConversionMap Abstract base class for coordinate conversion maps.
ScalarMap Pure scaling transformation: y = scalar * x.
LinearMap Affine transformation: y = scalar * x + offset.
ShiftMap Pure offset transformation: y = x + offset.
TableMap Lookup table with interpolation between anchor points.
ChainMap Composition of multiple maps: f(g(h(x))).
ConstantMap A ConversionMap that returns a constant value for any input.
IntervalToConstantMap Interval-to-constant map: each interval [x_i, x_{i+1}) maps to value_i.
InterpolationMap Bidirectional coordinate mapping using numpy.interp.
PiecewiseMap Map defined by different maps on different intervals.
SecondsToSamples Convert seconds to audio samples by multiplying by sample rate.
QuartersToFloatingMeasures Map quarters to floating measures.
QuartersToMeasureNumber Map quarters to measure number labels (no interpolation).
OutputNumberTypeError A float handed to a map declared to write fractions.

Alignment

Classes for connecting and aligning timelines.

TimelineGroup An array of timelines sharing one graphical start and end point.
AlignmentBundle The primary entry point for all alignment workflows.
SupportPolicy How to treat a transferred coordinate that falls outside alignment support.
AlignmentAnchor A coordinate pair associating one coordinate on timeline A with one
MatchClaim A claim that two events on different timelines correspond.
ClaimType The semantic kind of a MatchClaim, derived from its structure.
MatchClaimField The MatchClaim table: a SemanticField[MatchClaim] columnar store.
Provenance How an item was made (paradata) and who believes it.
Belief One actor’s belief in an item, at a date.
Projection An event standing on a timeline for an event not held there.
EventReference The address of one event: the timeline holding it and its ID there.
Resource A file the manifest names: one entry of its resources.
Integrity The digest of a resource’s raw bytes and the hash function computing it.
MatchGraph A graph of MatchClaims connecting events across timelines/groups.
MatchStamp A synchronized timestamp across multiple timelines.
MatchLine Ordered sequence of MatchStamps for a source timeline.
WarpMap Bidirectional coordinate warping derived from alignment data.
ClaimFilter Reusable filter for querying MatchClaims and related objects.
MatchFileContext Supplementary data required for .match file export.
NoteRecord Performance note record for .match format export.
SnoteRecord Score note record for .match format export.

Statements

Property–value statements and their provenance on a bundle, its timelines at any depth and its regions; a timeline and a bundle change them in place, a region returns a copy.

StatementsMixin The statements of a bundle, a timeline or a region, and their provenance.
MutableStatementsMixin Statements changed in place: a timeline’s and a bundle’s.
Region An identified part of a timeline defined by a TimeInterval.
LIBRARY_AGENT The agent an importer of this library names as stated_by by default.

Loaders

Data ingestion from various file formats.

Loader Shared lifecycle for all loader families.
EventData PyArrow-based storage for timeline events.
EventStore Abstract base class for collections of EventData.
SingleStore Store wrapper for a single EventData.
DictStore Generic EventStore with arbitrary named EventData tables.
EventLoader Abstract base class for event-producing loaders.
AudioLoader Load audio file metadata for creating physical timelines.
AudioInfo Metadata for an audio file.
RepoVizzLoader Load RepoVizz XML manifests or single CSV files for creating physical timelines.
RepoVizzInfo Parsed metadata from a RepoVizz CSV file (legacy mode).
EepNotesLoader Loader for EEP .notes alignment files.
CsvLoader Loader for CSV (comma-separated values) files.
TsvLoader Loader for TSV (tab-separated values) files.
LabLoader Loader for Audacity/Praat label files (.lab, .txt).
SoloLoader Loader for .solo performance-precision specimen files.
TabularLoader Vectorized base class for loading tabular data with column/field specs.
JsonLoader Configurable JSON normaliser producing flat pa.Table objects.
XmlLoader Configurable XML normaliser producing flat pa.Table objects.
Music21Loader Load symbolic scores using music21.
PartituraLoader Load symbolic scores using partitura.
Ms3Loader Load symbolic scores from DCML-style TSV files.
MeasureMapLoader Load MeasureMap JSON files into ScoreStore.
VerovioLoader Load an engraved score through the Verovio toolkit.
MidiLoader Abstract base class for MIDI loaders.
PerformanceMidiLoader Load performance MIDI files using mido.
ScoreMidiLoader Load score MIDI files using partitura or a mido fast path.
GraphicalLoader Factory for building GraphicalStore objects.
IIIFManifestLoader Load image metadata from IIIF Presentation API manifests.
DmosLoader Load the pages, systems and measures of a DMOS JSON file.
MeiFacsimileLoader Load the surfaces and zones of an MEI file’s facsimile.
TimeAxisPath Abstract definition of a time axis path through 2D space.
HorizontalLinePath Time axis as a horizontal line at fixed y.
VerticalLinePath Time axis as a vertical line at fixed x.
DiagonalLinePath Time axis as a diagonal (arbitrary straight) line.
ParametricPath Time axis defined by parametric functions x(t), y(t).
PiecewisePath A time axis made of consecutive pieces, read one after the other.
ATONLoader Load ATON format files (piano roll analysis data).
ScoreWarpLoader Load the time axis drawn into a ScoreWarp SVG.
MatchfileLoader Load Vienna Match (.match) alignment files via partitura.
TiliaJsonLoader Loader for TiLiA JSON annotation exports.
TiliaDictStore DictStore subclass with convenience properties for TiLiA timeline types.
PerformancePrecisionLoader Load a Performance Precision specimen directory as an AlignmentBundle.
ParangonadaLoader Load a parangonada CSV export as one multimodal AlignmentBundle.
MpmLoader Load an MPM-Toolbox MSM+MPM+MPR triple as one multimodal AlignmentBundle.
ListenHereLoader Load a Listen Here! alignment JSON file as one AlignmentBundle.
MapsLoader Load a MAPS alignment file and state it as MatchClaims.
MeiHeadLoader Read an MEI header and state what it says as statements.
MelodyLoader Read MeLODy’s Turtle and carry its triples as statements.
