LinearMap

LinearMap(
    scalar=1,
    offset=0,
    source_unit=None,
    target_unit=None,
    uid=None,
    name=None,
    output_number_type=None,
)

Affine transformation: y = scalar * x + offset.

This is the most general linear map, combining scaling and offset.

The format’s LinearMap type, which every affine map of the library is written as.

Attributes

Name Type Description
scalar CoordinateValue The multiplicative factor (default 1).
offset CoordinateValue The additive offset (default 0).

Examples

>>> # Convert ticks to quarters: y = x / 480
>>> tick_to_quarter = LinearMap(scalar=1/480, source_unit="ticks", target_unit="quarters")
>>> tick_to_quarter(480)
1.0
>>> # Temperature conversion: Celsius to Fahrenheit: y = 1.8x + 32
>>> c_to_f = LinearMap(scalar=1.8, offset=32)
>>> c_to_f(0)
32.0
>>> c_to_f(100)
212.0
>>> # Inverse map
>>> f_to_c = c_to_f.inverse()
>>> f_to_c(212.0)
100.0

Methods

Name Description
compose_with Compose with another LinearMap: (self then other).
from_pairs Build the line through the first and the last pair by position.
inverse Return the inverse map: y = (x - b) / a.
with_offset This map from another origin: the same line, shifted.

compose_with

LinearMap.compose_with(other)

Compose with another LinearMap: (self then other).

For y1 = a1x + b1 and y2 = a2y1 + b2: y2 = a2(a1x + b1) + b2 = (a1a2)x + (a2*b1 + b2)

Parameters

Name Type Description Default
other LinearMap The map to apply after this one. required

Returns

Name Type Description
LinearMap A new LinearMap equivalent to applying both in sequence.

from_pairs

LinearMap.from_pairs(pairs, *, source_unit, value_unit=None, origin=0)

Build the line through the first and the last pair by position.

The positions are read from origin (position - origin). The scalar is the values’ difference over the positions’ difference, the offset what is left at the first position, both in the numbers’ own arithmetic: exact pairs give an exact map, which writes its results as fractions where the value unit admits them, and pairs holding a float give a float map, which writes floats.

Every inner pair is checked against the line through the end pairs, evaluated exactly on the positions as given, before origin is subtracted: the position at which the line reaches the pair’s value must be its position, exactly for an exact calibration and within the error of a position computed in doubles otherwise (see :meth:ConversionMap.from_pairs). The line is never fitted.

Parameters

Name Type Description Default
pairs Sequence[CalibrationPair] (position, value) pairs, in any order: positions as numbers or coordinates, values as coordinates carrying the one unit they share or as numbers in value_unit. required
source_unit TimeUnit | str | None The unit of the positions. required
value_unit TimeUnit | str | None The unit of the values, the map’s target unit. Needed when a value is a number; a coordinate value must be in it. None
origin CoordinateValue | Coordinate Where the source axis starts, in the coordinates of the positions. 0

Returns

Name Type Description
Self The map through the pairs.

Raises

Name Type Description
TypeError If a value is a number and no value_unit is given.
ValueError If there are fewer than two pairs, two pairs share a position, a coordinate is in another unit than its axis, the end pairs read one value, or an inner pair lies off the line.

Examples

>>> m = LinearMap.from_pairs(
...     [(0, 1), (3, 2), (6, 3)], source_unit="points", value_unit="quarters"
... )
>>> m.scalar, m.offset
(Fraction(1, 3), Fraction(1, 1))
>>> m(1)
Fraction(4, 3)

inverse

LinearMap.inverse()

Return the inverse map: y = (x - b) / a.

with_offset

LinearMap.with_offset(offset)

This map from another origin: the same line, shifted.

A new map with this map’s scalar, units and the output representation it was given, and offset in place of its own; it gets its own ID and no name. A child timeline reads its measure map through its parent’s map from its own origin (with_offset(0)), in the same number type as the parent.

Parameters

Name Type Description Default
offset CoordinateValue The additive offset of the new map. required

Returns

Name Type Description
LinearMap The new map.

Examples

>>> m = LinearMap(scalar=Fraction(1, 480), offset=3, output_number_type="float")
>>> moved = m.with_offset(0)
>>> moved.scalar, moved.offset
(Fraction(1, 480), 0)
>>> moved.output_number_type == m.output_number_type
True
