How to Represent Areas of Page Images as Boxes

BoundingBox, Quadrilateral and Box events: shapes in image space and their xywh, SVG and MEI forms, the time path of a page made from its boxes, a page built of accolades with their measures, DmosLoader, MeiFacsimileLoader, an IIIF volume along given paths, and boxes.parquet in a package

How to Represent Areas of Page Images as Boxes

A measure on a scanned page, a zone of an MEI facsimile and a rectangle drawn on an analytical diagram are all areas of an image. An image has no time axis of its own: neither its width nor its height is one. It has one only along a time path, the line a reader follows through it. On a page of a score the path runs along the first accolade (a system, one line of the page) from left to right, then along the second, and so on. A page is therefore built of its accolades, laid end to end, and a volume of its pages. Along one accolade each area is an interval: it starts where the area starts in x, counted from the accolade’s left end, and lasts as long as the area is wide.

The library holds both views in one event, the Box. A Box keeps the area as the source states it, its shape, in the image’s own pixels: either a BoundingBox (x, y, width, height, the IIIF and Media Fragments xywh) or a Quadrilateral (four corners, for the skewed measures of a scan). Its start and duration are the interval on the timeline. The two always agree, and the library refuses a Box in which they do not.

This guide builds shapes and writes them in the forms other formats use, makes the time path of a page from the areas drawn on it, builds the page from its accolades and puts Boxes on them, shows the rectangles of a graphical analysis as Boxes on its image crops, reads pages from a DMOS page layout and from an MEI facsimile, lays the pages of an IIIF volume along their paths, and writes a bundle holding Boxes as a package and reads it back.

Setup

Install the library with pip install timetoalign. Every source file this guide reads, except the annotation table of the graphical analysis, is written by the guide into a temporary directory. A timeline’s Boxes come back as the events of any type do: get_events(event_type="Box") selects them and get_field(Box) reads them as Box objects, each with its ID, interval and shape. The helpers: box_table shows them one per row with the x extent of each shape beside the interval, segment_table lists the timelines a page or a volume is built of, refusal runs a call the library refuses and prints its message, write writes a source file into the temporary directory, and show prints one key of a manifest file.

import json
import tempfile
from fractions import Fraction
from pathlib import Path

import pandas as pd
from timetoshare import dumps, loads

from timetoalign import (
    AlignmentBundle,
    BoundingBox,
    Box,
    ContinuousLogicalTimeline,
    DiscreteGraphicalTimeline,
    DmosLoader,
    IIIFManifestLoader,
    MeiFacsimileLoader,
    Quadrilateral,
)
from timetoalign.loader.graphical import TimeAxisPath
from timetoalign.testdata import ensure_data
from timetoalign.timelines import SegmentLine

FILES = Path(tempfile.mkdtemp())


def box_table(timeline):
    """One row per Box: its interval on the timeline and its shape's x extent."""
    return pd.DataFrame(
        [
            {
                "id": box.id,
                "start": box.start.value,
                "duration": box.duration.value,
                "shape": type(box.shape).__name__,
                "x_min": box.shape.x_min.value,
                "x_max": box.shape.x_max.value,
            }
            for box in timeline.get_events(event_type="Box").get_field(Box)
        ]
    )


def segment_table(line):
    """One row per timeline a page or a volume is built of, in reading order."""
    return pd.DataFrame(
        [
            {
                "id": child_id,
                "name": line.get_child(child_id).name,
                "offset": line.get_child_offset(child_id).value,
                "length": line.get_child(child_id).length.value,
            }
            for child_id in line.list_children()
        ]
    )


def write(name, text):
    """Write a source file into the temporary directory."""
    (FILES / name).write_text(text, encoding="utf-8")


def refusal(call):
    """Run a call the library refuses and print its message."""
    try:
        call()
    except ValueError as error:
        print(error)


def show(manifest_path, key):
    """Print one key of a manifest file as canonical YAML."""
    print(dumps({key: loads(manifest_path.read_text(encoding="utf-8"))[key]}), end="")

Shapes

A shape is an area of an image in image space: the origin is the image’s top-left corner, x runs right and y down, and every number is in one unit and one number type. On pixels the numbers are integers.

A BoundingBox is built from its top-left corner and its extent with from_xywh(). This one is a rectangle of the graphical analysis used below: x 385, y 46, 139 pixels wide, 20 high.

rect = BoundingBox.from_xywh(385, 46, 139, 20, unit="pixels")
rect
BoundingBox(x=Coordinate(385, pixels), y=Coordinate(46, pixels), width=Duration(139, pixels), height=Duration(20, pixels))

A shape writes itself in the forms other formats use: its dict form (as a manifest holds it), a Media Fragments and IIIF selector, the points of an SVG polygon (corners in the order top-left, top-right, bottom-right, bottom-left), and the attributes of an MEI zone, whose lrx and lry are the lower-right corner (x + width, y + height).

{
    "dict form": rect.to_dict(),
    "media fragment": rect.as_media_fragment(),
    "SVG points": rect.as_svg_points(),
    "MEI zone": rect.as_mei_zone(),
}
{'dict form': {'x': 385, 'y': 46, 'width': 139, 'height': 20},
 'media fragment': 'xywh=385,46,139,20',
 'SVG points': '385,46 524,46 524,66 385,66',
 'MEI zone': {'ulx': '385', 'uly': '46', 'lrx': '524', 'lry': '66'}}

Each form reads back into the same box: from_media_fragment() reads the selector, from_corners() the corners an MEI zone states.

(
    BoundingBox.from_media_fragment("xywh=385,46,139,20", unit="pixels") == rect,
    BoundingBox.from_corners(385, 46, 524, 66, unit="pixels") == rect,
)
(True, True)

A Quadrilateral holds four corners, so it can follow a measure whose sides are not upright. from_points() takes the points in any order the source writes them, with order= naming the corner each one is; the optical music recognition tool DMOS writes a measure top-left, top-right, bottom-left, bottom-right. These are the corners of the first measure of the first system on page 2 of a printed score in Gallica (ark:/12148/bpt6k11620688), as DMOS states them; measure 2 follows it on that system, and measure 3 is the first of the second system. The quadrilateral keeps the corners in the canonical order.

DMOS_MEASURE_ORDER = ("top_left", "top_right", "bottom_left", "bottom_right")
MEASURE_1 = [[1221, 1589], [2151, 1589], [1221, 2266], [2161, 2266]]
MEASURE_2 = [[2151, 1589], [2766, 1589], [2161, 2266], [2775, 2266]]
MEASURE_3 = [[971, 2493], [1935, 2493], [971, 3192], [1945, 3192]]

measure_1, measure_2, measure_3 = (
    Quadrilateral.from_points(corners, order=DMOS_MEASURE_ORDER, unit="pixels")
    for corners in (MEASURE_1, MEASURE_2, MEASURE_3)
)

SVG and MEI points may start at any corner and run in either direction. from_svg_points() reads such a list and brings it into the canonical order; here the list starts at the bottom-right corner and runs anticlockwise.

True

A shape’s numbers are never rounded. A whole number given as a float is taken (385.0 is 385); a pixel position of 385.5 cannot be held on an integer axis and is refused.

BoundingBox.from_xywh(385.0, 46, 139, 20, unit="pixels") == rect
True
refusal(lambda: BoundingBox.from_xywh(385.5, 46, 139, 20, unit="pixels"))
A shape's x is 385.5, which pixels as int cannot hold exactly: geometry is never rounded.

The time path of a page

No image has a time axis until its path through the image is defined. A set of boxes makes one: TimeAxisPath.from_boxes() takes the areas of one page in reading order and returns a PiecewisePath, one horizontal piece per accolade.

DMOS states the systems of the page as areas too (corners top-left, bottom-left, top-right, bottom-right). Each system is one accolade, so accolades= gives every box its own label.

PAGE_URL = "https://gallica.bnf.fr/iiif/ark:/12148/bpt6k11620688/f2"
DMOS_SYSTEM_ORDER = ("top_left", "bottom_left", "top_right", "bottom_right")
SYSTEM_1 = [[1221, 1589], [1221, 2266], [4097, 1589], [4101, 2266]]
SYSTEM_2 = [[971, 2493], [971, 3192], [4104, 2493], [4112, 3192]]
system_areas = [
    Quadrilateral.from_points(corners, order=DMOS_SYSTEM_ORDER, unit="pixels")
    for corners in (SYSTEM_1, SYSTEM_2)
]

path = TimeAxisPath.from_boxes(system_areas, accolades=[1, 2])
path.pieces
(HorizontalLinePath(x0=1221, x1=4101, y=Fraction(3855, 2), tolerance=Fraction(677, 2)),
 HorizontalLinePath(x0=971, x1=4112, y=Fraction(5685, 2), tolerance=Fraction(699, 2)))

A piece spans its boxes exactly: x0 is their least x and x1 their greatest, y is the middle of their y extent and tolerance half of it, so the strip y ± tolerance is the accolade’s height. Nothing is rounded: the first system spans y 1589 to 2266, whose middle is 3855/2.

The path’s length is the sum of its pieces, 2880 + 3141 pixels, and each piece starts on the path where the ones before it end.

(path.offsets, path.length)
((0, 2880), 6021)

The path converts between its own coordinate and the image’s (x, y). Coordinate 2880 is the left end of the second accolade, x 971; the point (2151, 1900) lies in the first accolade’s strip, 930 pixels from its left end; a point between the two strips is on no piece.

(path.to_2d(2880), path.from_2d(2151, 1900), path.from_2d(2151, 2400))
((971, Fraction(5685, 2)), 930, None)

Where a source states no accolades, accolades= is left out and from_boxes() finds them: reading on, the left edges of the boxes grow within an accolade and fall back at the start of the next, so a box begins a new accolade when its left edge lies left of the previous box’s by more than half the span of all left edges. Of the three measures, the third falls back from x 2151 to 971 and begins the second piece; each piece spans the measures given, not the whole system.

TimeAxisPath.from_boxes([measure_1, measure_2, measure_3]).pieces
(HorizontalLinePath(x0=1221, x1=2775, y=Fraction(3855, 2), tolerance=Fraction(677, 2)),
 HorizontalLinePath(x0=971, x1=1945, y=Fraction(5685, 2), tolerance=Fraction(699, 2)))

A page, its accolades and their measures

The timelines mirror the path. An accolade is a timeline as long as its piece, and it says which area of which image it stands for in its meta: meta["box"] is that area as a shape’s dict form, in the image’s space, and meta["image"] names the image. Identifiers are given at creation: uid= for a timeline, id= for a Box.

Box.from_shape() makes the Box of a shape on a timeline. Its origin is the x at which the timeline stands in the image, here the accolade’s x_min. The Box’s interval follows from the shape:

  • start = the shape’s x_min − the timeline’s origin,
  • duration = the shape’s x_max − x_min.
system_1, system_2 = (
    DiscreteGraphicalTimeline(
        length=(area.x_max - area.x_min).value,
        unit="pixels",
        uid=f"system_{number}",
        name=f"System {number}",
        meta={"box": area.to_dict(), "image": PAGE_URL},
    )
    for number, area in enumerate(system_areas, start=1)
)
system_1.add_events(
    [
        Box.from_shape(measure_1, origin=system_areas[0].x_min, id="m1"),
        Box.from_shape(measure_2, origin=system_areas[0].x_min, id="m2"),
    ]
)
system_2.add_events([Box.from_shape(measure_3, origin=system_areas[1].x_min, id="m3")])

Measure 1 starts at x 1221 of the image and the accolade stands at x 1221, so the measure starts at 0 on the accolade; measure 2 starts at 2151, which is 930 on the accolade.

The page is the segment line of its accolades, in reading order. It names its image and states no meta["box"]: its axis is the accolades laid end to end, which is no area of the image.

page = SegmentLine[DiscreteGraphicalTimeline](

page.append_segment(system_1, name="System 1")

The page is as long as the path, 6021 pixels, and its accolades start at the path’s offsets. A coordinate on the page is therefore a position along the path, not an x of the image: measure 3 starts at x 971 of the image, at 0 on its accolade, and at 2880 on the page.

A Box whose interval contradicts its shape is refused, on every path that adds events. Forgetting the origin is the common case: the Box below starts at 1221, the shape’s x in the image, but on an accolade standing at x 1221 of its image the shape starts at 0.

refusal(lambda: system_1.add_events([Box.from_shape(measure_1, id="m1_again")]))
Box 'm1_again' starts at 1221 on timeline 'system_1', but its shape starts at x 1221 and the timeline stands at x 1221 of its image (meta["box"]): its start is 0.

The rectangles of a graphical analysis

How to Transfer Annotations Between Graphical Analyses places eleven rectangles, drawn on five image crops of an analytical diagram, on a segment line of those crops. The diagram is read along one horizontal line per crop, one crop after the other, so the crops are to the analysis what accolades are to a page. Each rectangle is stated in its image’s pixels, and each crop starts a few pixels right of its image’s left edge. As Boxes, the rectangles keep their shapes and each crop states where it stands in its image.

DATA_DIR = ensure_data("thoresen")
annotations = pd.read_csv(DATA_DIR / "thoresen_test.tsv", sep="\t")

# Each crop: its image, its left and right x in the image, the image's height
CROPS = [
    ("thoresen_2010_form-building-patterns_p90-91_page1_1.jpeg", 8, 874, 264),
    ("thoresen_2010_form-building-patterns_p90-91_page1_2.jpeg", 7, 874, 270),
    ("thoresen_2010_form-building-patterns_p90-91_page1_3.jpeg", 7, 874, 266),
    ("thoresen_2010_form-building-patterns_p90-91_page1_4.jpeg", 8, 872, 272),
    ("thoresen_2010_form-building-patterns_p90-91_page2_1.jpeg", 9, 873, 278),
]

analysis = SegmentLine[DiscreteGraphicalTimeline](
    length=0, unit="pixels", uid="dgt_2", name="Thoresen 2010"
)
for number, (image, x0, x1, height) in enumerate(CROPS, start=1):
    area = BoundingBox.from_xywh(x0, 0, x1 - x0, height, unit="pixels")
    crop = DiscreteGraphicalTimeline(
        length=x1 - x0,
        unit="pixels",
        uid=f"crop_{number}",
        meta={"box": area.to_dict(), "image": image},
    )
    on_crop = annotations[annotations["image_filename"] == image]
    crop.add_events(
        [
            Box.from_shape(
                BoundingBox.from_xywh(**json.loads(rectangle), unit="pixels"),
                origin=x0,
                id=rectangle_id,
            )
            for rectangle_id, rectangle in zip(
                on_crop["graphical_element_id"], on_crop["rect_coords_json"]
            )
        ]
    )
    analysis.append_segment(crop, name=f"seg_{number}")

crop_2 = analysis.get_child("crop_2")

A DMOS page layout

DMOS writes the layout it recognises on each page as JSON: per page its image (page_url) and its systems, per system its region and its measures, each with its region. Region corners are in the orders seen above. create_timeline() reads the whole file as one volume: a segment line of its pages, each page a segment line of its systems’ accolades, each measure a Box of its system’s accolade with its quadrilateral. The identifiers are given in the same call. uid names the volume; page_ids, accolade_ids and box_ids each name every element of their kind, as a sequence of IDs in document order or as a template filled from page (the page’s position, from 1), accolade (its position on its page), box (its position in its accolade) and n (the running count). DMOS states no measure numbers, so box_ids="m{n}" numbers the measures through the score.

An MEI facsimile

An MEI facsimile holds one surface per page image, with a graphic naming the image and one zone per area; elements of the encoding point to their zones with @facs. The first surface below is a page of a chorale of the Anhaltisches Choralbuch digital edition (CC BY 4.0) with its nine measure zones, and two measures pointing to the first two. The second surface is page 2 of the Gallica score, holding measure 1 as the zone as_mei_zone() wrote above, its corners as points.

create_timelines() reads one root timeline per surface, a page built of the accolades of that path: its ID is the surface’s xml:id, its name the surface’s @n, its meta["image"] the graphic’s target. The graphic’s size is on no timeline. Each accolade is named accolade_K and states the strip of its piece as meta["box"]. Each zone becomes a Box of the accolade it lies on, with the zone’s xml:id as its ID: a BoundingBox from ulx … lry, or a Quadrilateral where the zone has points. Where the rule of the left edges does not find a page’s accolades (zones not listed accolade by accolade, say), the path returned by create_paths() is corrected or written anew and given back as paths=, keyed by the surface’s xml:id. zone_types= selects the zones taking part by their @type, and box_ids= replaces the zones’ xml:ids, as in the DMOS section; create_timeline() gives the whole facsimile as one volume.

An IIIF volume

An IIIF Presentation manifest lists the page images of a volume as canvases, each with its width and height. It states no areas, so nothing in it says where the page is read: IIIFManifestLoader builds a timeline only along the time path it is given for a canvas. The excerpt below is the Gallica manifest of the score above (Presentation 2), trimmed to its first three canvases.

MANIFEST_ID = f"{SCORE_URL}/manifest.json"
CANVAS = SCORE_URL + "/canvas/f{}"
write(
    "manifest.json",
    json.dumps(
        {
            "@context": "http://iiif.io/api/presentation/2/context.json",

            "label": "Exemplaire localisé à la Médiathèque Hector Berlioz (CNSMDP), D-9658 (1)",

                {
                    "@type": "sc:Sequence",

Boxes in a package

A bundle keeps its timelines in a TimeToShare manifest; the Boxes are events and live beside it. The registry (registry.parquet) holds one row per Box with its timeline’s ID and its position on the axis of the timeline’s root (a measure of an accolade at its place on the page), and the Box table (boxes.parquet) its shape, keyed by its ID; the manifest names the registry among its resources with the type Registry. The bundle below holds the page built by hand, with its two accolades and their three measures, and a logical timeline beside it.

score = ContinuousLogicalTimeline(length=Fraction(8), uid="score", name="Score")
bundle = AlignmentBundle(name="Page and score")
bundle.add_timeline(page)
bundle.add_timeline(score)

manifest_path = bundle.to_file(FILES / "package" / "page.tts.yaml")
sorted(path.name for path in manifest_path.parent.iterdir())

read = AlignmentBundle.from_file(manifest_path)
